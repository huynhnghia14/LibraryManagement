# LibraryManagement

Hệ thống quản lý thư viện.

## Cấu trúc thư mục

LibraryManagement/
├── include/     (header files)
├── src/         (source files)
├── data/        (file dữ liệu mẫu)
├── docs/        (báo cáo, hình ảnh)
├── tests/       (test cases)
├── Makefile
└── README.md

## Hướng dẫn biên dịch và chạy

- Biên dịch: make
- Chạy chương trình: make run
- Dọn dẹp: make clean
